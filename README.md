# DeepSeek 智能解释 - Edge 浏览器扩展

> 选中网页上的任意文本，DeepSeek 立刻在鼠标旁弹出解释卡片。

这是一款轻量级 Edge 浏览器扩展。无需跳转页面、无需复制粘贴——在浏览网页时选中文字，DeepSeek AI 即时给出分点解释。英文给英文释义，中文给中文解读，结合网页上下文理解，支持复制和下载。

## 前置条件

- Edge 浏览器（Chrome 亦可）
- DeepSeek API Key（[点击获取](https://platform.deepseek.com/api_keys)）

## 功能

- **划词解释**：选中文本弹出解释，取消选中自动消失
- **触发方式可选**：支持「选中自动搜索」和「右键菜单搜索」两种模式，随时切换
- **网页上下文**：自动提取选中文本所在段落的上下文，让解释更准确（可选开关）
- **分点解析**：释义、词性、用法、背景等信息分点呈现
- **一键复制**：点击复制按钮将解释写入剪贴板
- **一键下载**：将解释保存为 TXT 文件，自动附带选中原文、解释内容、来源页面 URL 与生成时间，存至浏览器默认下载目录
- **多模型**：支持 DeepSeek-V4-Flash 和 DeepSeek-V4-Pro
- **深度思考**：可选开启思考模式，支持高/最高两档思考强度

## 安装

```bash
git clone https://github.com/zdjmrq/siwenyudecangku.git
```

克隆后可以删除 【.git】 文件夹与 【README.md】 文件（不影响扩展运行），保持文件夹干净。

1. 打开 Edge，地址栏输入 `edge://extensions`（或在拓展插件图标中点击“管理拓展”）
2. 开启左侧「开发人员模式」
3. 点击「加载解压缩的扩展」，选择克隆后的文件夹
4. 点击工具栏扩展图标，填入 DeepSeek API Key（[获取地址](https://platform.deepseek.com/api_keys)）
5. 去任意网页选中文字，即可看到解释

## 使用技巧

- 在设置面板中切换「触发方式」：「选中自动搜索」更快捷，「右键菜单搜索」避免误触发，随时切换无需刷新页面
- 将 Edge 默认下载目录设为你的笔记文件夹，下载的解释文件会自动归档
- 开启「深度思考模式」（建议搭配 V4-Pro 模型使用），可选高/最高两档思考强度
- 按【Esc】可以快速关闭弹窗

## 技术栈

- Manifest V3
- Content Script（划词检测 + 浮动卡片 + 直接 API 调用）
- DeepSeek Chat Completions API
